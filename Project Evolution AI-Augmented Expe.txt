Project Evolution: AI-Augmented Expense Tracker

    The Origin: Started as a local index.html on your Acer laptop to track and categorize personal expenses.

    The Migration: Moved to GitHub Pages for cross-device accessibility, realizing the limitations of public static hosting for private data.

    The Security Hardening:

        Integrated Firebase Authentication to replace local access with secure Google OAuth and Email/Password sign-in.

        Migrated data storage to Google Cloud Firestore.

        Implemented Firestore Security Rules (Version 2) using recursive wildcards to ensure total data isolation (Users can only read/write their own userId path).

    The Validation: Confirmed security effectiveness by testing in Private/Incognito mode, verifying that unauthorized requests correctly return a 400 Malformed Request/Access Denied error.
